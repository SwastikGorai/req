## Design details (LLD)

*Reference material — consult if a task is unclear. Before starting, refine function signatures against the completed code; preserve the behavioral contract linked below.*

**Refined 2026-09-06 against the Phase 3 tree** (module `req`; `model.Collection/Item/Folder/Request/Entry/Body`, `store.Workspace` with `LoadCollection`/`SaveCollection`/`Revision`/`ErrNotFound`/`*ConflictError`; CLI dispatch in `root.go`, hand-rolled flag parsing, `parseGlobals`):

- **Path grammar:** `CollectionName[/Folder…/Leaf]`, split on `/`. Every segment must satisfy `model.ValidName`; empty segments (leading/trailing/doubled `/`), `.`/`..` and `\` are usage errors. The first segment names the collection by its unique **Name** (duplicate collection names are rejected at create, so names are unambiguous).
- `internal/store/selectors.go` — `SplitPath(path string) ([]string, error)`; sentinel `ErrInvalidPath`; `ResolvedPath{Collection model.Collection; Rev Revision; Segments []string; Item *model.Item}` (`Item` nil at collection root); `(ws) ResolvePath(ctx, path) (ResolvedPath, error)` — a missing collection or segment wraps `ErrNotFound` and names the failing segment.
- `internal/store/collections.go` — `(ws) ListCollections(ctx) ([]model.Collection, error)` (strict load of every file, sorted by Name); `(ws) CreateCollection(ctx, name string) (model.Collection, error)` (duplicate name across stored collections wraps new sentinel `ErrDuplicateName`; `NewID("col")`, empty items, saved as a fresh file via `SaveCollection(…, "")`).
- `internal/store/mutations.go` — `(ws) CreateFolder(ctx, path string, parents bool) ([]string, error)` (returns created folder names); `(ws) CreateRequest(ctx, path string, req model.Request, parents bool) error`. Both need ≥2 segments; they walk existing segments (continuing *through* a request item is an error), require `parents` for missing intermediate folders (`--parents` creates them with `NewID("fld")`; it never creates the collection itself), and reject an existing leaf or same-named sibling via `ErrDuplicateName`. Persistence goes through `SaveCollection` with the loaded `Revision`, so a concurrent create loses honestly via `*ConflictError` (exit 7).
- `internal/execution` (new package) — `Outgoing` (fully resolved request + policy: `Method, URL string; Headers [][2]string; Body []byte; Timeout time.Duration; InsecureTLS, FollowRedirects, FailOnHTTPError bool`); `Overrides{Method, URL string; Queries, Headers [][2]string; Body []byte; BodyMode string}` (structural only); `Policy{Timeout, InsecureTLS, FollowRedirects, FailOnHTTPError}`; `Prepare(saved model.Request, ov Overrides, pol Policy) (Outgoing, error)` — enabled entries only; CLI queries/headers **append after** saved entries; `--method/--url/--body/--json` **replace**; content type defaults to `application/json`/`text/plain` by body mode unless an explicit Content-Type header exists (case-insensitive); remaining `{{…}}` placeholders, non-absolute http(s) URL, invalid method token and not-yet-supported body types (`urlencoded`/`multipart`/file) are errors. `Execute(ctx, Outgoing, stdout, stderr) int` — the send/render core moved out of `runSend` (query append without re-encoding, status line to stderr, body to stdout, exit 0/3/4/130). `cli/send.go` delegates to it; `req run PATH` reaches the identical execution path through the same two functions.
- `internal/cli` — new handlers: `collection.go` (`collection create NAME` → status line, `collection list` → `NAME\tID` sorted by name), `folder.go` (`folder create PATH [--parents]`), `request.go` (`request create PATH --method M --url U [-H Name:value]… [--query k=v]… [--body TEXT | --json JSON] [--parents]`; `request list PATH` → `NAME\tMETHOD\tURL` for request children in stored order; `request show PATH` → the item's `request` object as indented JSON), `tree.go` (`tree PATH`; stored sibling order; folder lines `Name/`, request lines `Name  METHOD URL`; two-space indent per depth), `run.go` (`run PATH [same structural override flags as send plus --timeout/--no-follow/--insecure/--fail]`). Shared helper resolves the workspace from `inv.workspace` (Open) or discovery; missing workspace → exit 2. CRUD status messages go to **stderr**; list/show/tree output to stdout. `root.go` routes the new commands and updates the usage text. Overrides affect only the execution copy; nothing rewrites the stored file on `run`.
- **Exit-code mapping for the new commands:** malformed paths, not-found collection/folder/request, duplicate names, flag/validation errors → 2; IO/lock/conflict/malformed stored file → 7. `req run` exits 2 on any remaining `{{…}}` placeholder (substitution arrives in Phase 6+; a literal placeholder is never sent). `--json` at request-create time is validated unless it contains `{{…}}` (stored verbatim; validated after substitution per §3).
- Full fixed behavior and edge cases: [IMPLEMENTATION.md](../IMPLEMENTATION.md). Record deviations explicitly; a shorter phase file does not remove requirements.
