- **Compatibility safety:** Invalid names/IDs are deterministically sanitized in lenient mode and reported as structured warnings. Strict mode rejects any warning before a write. Explicit name collisions return the existing duplicate error; default collisions use deterministic suffixes. Unsupported auth, method or body data is retained in `ImportMetadata` and blocks execution rather than silently becoming unauthenticated or otherwise lossy. File attachments are stored as untrusted paths and are not read during import. Disabled variables remain persisted but are filtered from active run-time scopes.
- **URL policy:** String URLs are preserved. Structured URLs retain raw text when present; structured query entries duplicated by that raw query are not emitted twice, while distinct entries remain native query data. Structured `:variable` path segments use the imported default when present and otherwise become native `{{variable}}` placeholders.
